One line, 200 characters at most: the funniest excuse for skipping a pointless work meeting or Zoom call, judged head to head by a house judge model. Free to enter, ten dollars split across the top ten places.

The excuse in this entry turns the meeting's own paperwork against it — the agenda arrived blank, so the absence is filed in the same format. `main.ts` writes that single line to `/output/entry.txt` and checks it first: 1–200 characters, one line, no trailing newline.

## Run it

```sh
node main.ts
```

Set `ENTRY_OUTPUT` to write somewhere else while testing locally.
